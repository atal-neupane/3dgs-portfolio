Project Overview

This project implements an end-to-end 3D Gaussian Splatting pipeline, from multi-view image capture and camera reconstruction through Gaussian optimization and interactive browser rendering.

Camera poses and a sparse reconstruction were generated with COLMAP. The reconstructed scene was then trained using the GraphDeco implementation of 3D Gaussian Splatting on an NVIDIA RTX 3050 laptop GPU with 6 GB of VRAM.

The resulting Gaussian representation contains 238,078 trained primitives. For browser delivery, a separate SOG representation is used while the original GraphDeco PLY output is preserved independently.

Implementation

3D Reconstruction

Multi-view images are processed with COLMAP to estimate camera parameters, poses, and a sparse 3D reconstruction used to initialize Gaussian Splatting.

Gaussian Splatting

The GraphDeco 3DGS implementation optimizes explicit Gaussian primitives for novel-view rendering.

GPU Rendering

Training and server-side rendering use PyTorch and CUDA on an NVIDIA RTX 3050 with 6 GB VRAM.

Web Deployment

A separate SOG representation is hosted remotely and rendered interactively in the browser using WebGPU and SuperSplat.

The current web representation is a deployment copy of the trained model. The original GraphDeco PLY output is preserved separately as the source reconstruction artifact.

Research Direction

This implementation also serves as the baseline for ongoing MSc research into memory-efficient 3D Gaussian Splatting for memory-constrained devices.

The research direction investigates reducing Gaussian redundancy and representation size while studying the trade-offs between model size, GPU memory, rendering quality, and rendering speed.
