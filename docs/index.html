Memory-Efficient 3D Gaussian Splatting

A 3D Gaussian Splatting project focused on real-time scene reconstruction and rendering on memory-constrained hardware.

Interactive 3D Reconstruction

Explore the reconstructed scene directly in the browser. The model is rendered using WebGPU and supports interactive orbit, pan, and zoom controls.

Use your mouse to orbit, pan, and zoom around the reconstruction.

Project Overview

This project implements a complete 3D Gaussian Splatting pipeline, starting from multi-view images and camera reconstruction with COLMAP, followed by Gaussian Splatting training and browser-based WebGPU visualization.

The project is designed around the practical challenge of running 3D reconstruction and visualization workloads on hardware with limited GPU memory.
